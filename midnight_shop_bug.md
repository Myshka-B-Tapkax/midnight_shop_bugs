# Баг: НПС зависает при одновременном объяснении информации о товаре двум НПС в игре «Полуночный магазин»

## Описание
В игре «Полуночный магазин» (от Alawar) при одновременном объяснении двум НПС у стойки с хлебом 
один из НПС зависает с вопросительным знаком. Действие «Объяснить про товар» не убирается, 
НПС остаётся на месте. Игра не даёт завершить день.

## Примечание
Баг найден 16.08.2026. Воспроизводится редко — примерно 1 раз на 15 попыток.
Баг воспроизводится при одновременном действии на двух НПС.

## Шаги воспроизведения
1. Начать новый день в игре «Полуночный магазин»
2. Дождаться двух НПС у стойки с хлебом
3. Одновременно выполнить действие «Объяснить про товар» на обоих НПС
4. Наблюдать за НПС

## Ожидаемый результат
Оба НПС получают объяснение, значки «?» исчезают, НПС уходят.

## Фактический результат
Один НПС зависает с вопросительным знаком. Действие не убирается. День не заканчивается.
